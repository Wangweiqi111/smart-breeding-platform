# 智慧养殖平台

一个面向养殖场景的轻量级管理系统，纯前端实现，无需后端服务器。
数据保存在浏览器 `localStorage`，可直接接入下位机（STM32 等）通过串口上报传感器数据。

## 页面结构

| 页面 | 文件 | 说明 |
| --- | --- | --- |
| 首页 | `index.html` | 平台介绍与养殖政策展示 |
| 养殖系统 | `system.html` | 存栏台账、环境曲线、设备状态、串口接入 |
| 登录 | `login.html` | 账号校验、记住密码、登录态 |
| 注册 | `register.html` | 用户名 / 手机号 / 密码校验、密码强度提示 |

## 功能

### 1. 存栏统计（养殖数量管理）

不是写死的数字，而是由流水台账自动计算：

```
当前存栏 = 入库 − 出栏 − 淘汰
```

- 支持按栋舍、品种录入入库 / 出栏 / 淘汰记录，随时删除
- 自动汇总总存栏、母猪存栏、仔猪存栏、累计出栏
- Canvas 手绘分栋舍存栏柱状图
- **盘点核对**：输入现场实盘头数，与台账应有数比对，输出盘盈 / 盘亏并可一键写入调整记录
- 预留视觉识别接入：`window.LivestockVision.recognize(imageFile)` 返回头数后，
  页面会自动写入一条来源为「视觉识别」的台账记录，存栏数随之更新

### 2. 环境监控

- 温度 / 湿度 / 氨气三项实时数值 + 阈值告警（温度 18–28℃、湿度 ≤75%、氨气 ≤20ppm）
- Canvas 手绘历史曲线（无图表库），可切换指标，最多保留 120 个采样点
- **串口接入**：点击「连接串口（USB）」，通过 Web Serial API 读取下位机数据，
  支持两种报文格式（换行结束）：

  ```
  {"temp":24.5,"hum":62,"nh3":12}
  TEMP:24.5,HUM:62,NH3:12
  ```

  页面会显示最近 8 条原始报文与解析结果，便于调试

### 3. 设备状态

温控、投喂、监控、通风四路设备可手动开 / 关，状态持久化；关闭的设备会计入顶部告警数。

### 4. 账号体系

- 注册：用户名 ≥3 位、手机号 11 位、密码 ≥6 位、两次输入一致、用户名与手机号唯一
- 密码使用浏览器 Web Crypto API 做 SHA-256 哈希后存储
- 登录支持「记住密码」（保存在本机，公用电脑请勿勾选）
- 演示账号：`demo` / `123456`

## 技术栈

- HTML + CSS + **原生 JavaScript（ES6）**，无框架、无构建工具
- Canvas 2D 手绘图表（折线图 / 柱状图）
- `localStorage` 数据持久化
- Web Crypto API（SHA-256）
- Web Serial API（串口通信，Chrome / Edge，需 https 或 localhost）

## 本地运行

串口功能需要安全上下文，请通过 http 打开而不是双击文件：

```bash
cd wed_demo
python -m http.server 8765
# 浏览器访问 http://127.0.0.1:8765/
```

## 说明

- 本项目为课程与自学作品，**不含后端与数据库**，账号与业务数据均存在浏览器本地，
  仅作演示用途，不适用于生产环境。
- 模拟数据模式每 3 秒生成一个随机游走的采样点；连接串口后自动停止模拟，改用真实上报数据。
- 目前未接入任何图像识别模型，页面中的「视觉识别」按钮为演示接口调用流程的模拟。
